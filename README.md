# Fruitful Africa

**Fruitful Africa** is an ecommerce platform that aims to connect vendors offering exportable goods, craft textiles, and foodstuffs with global diaspora buyers.

---

## 🛠️ Tech Stack

- **Frontend**: Next JS, TypeScript
- **Styling**: Tailwind CSS
- **Version Control**: Git & GitHub

---

## 🚀 Getting Started

### 📥 Installation

```bash
# Clone the repo
git clone https://github.com/EmmyRecent/fruitful-africa.git

# Navigate into the project
cd fruitful-africa

# Install dependencies
npm install

# Run locally
npm run dev
```
